# 职业使用场景

根据用户的交付物和证据包选择工作流，不要根据行业热词判断。

## 采购决策与供应商评估

内部采购、供应商续约或采购建议报告由报价单、合同、认证证书、检测报告、履约记录、发票、付款回单或审批纪要支持时，使用 `procurement-zh`。

重点核对价格是否可比、税费与运费口径、产品规格、主体身份、证书有效期、绩效分母、收款方、节省金额计算，以及建议是否超出审批证据范围。

招投标方案、资格预审材料和技术响应文件同样可以使用该工作流。重点核对资质、业绩、报价、技术参数和事实承诺能否回到招标文件、合同、证书、检测报告、项目记录或其他原始材料。

用户要求逐条核验招标条款与投标响应时，可将响应项作为待审结论、将招标条款和证明材料作为证据，输出结论—证据台账、差异和人工决定。若还需标准技术偏离表、评分项判定或法律合规结论，应另行提供结构化条款、输出模板和专业复核规则；不得把“存在支持证据”直接等同于“满足全部招标或法律要求”。

## 运营或管理报告

月报、季报、仓储、服务、销售、质量或绩效报告由系统导出、KPI 工作簿、事故记录、SLA 文件和财务结算支持时，使用 `operations-zh`。

重点核对期间、地区、分母、取消和重复数据处理、工作日与自然日口径、税费处理及来源冲突。

## 咨询与行业研究交付

客户报告、市场研究、政策简报、尽调备忘录或管理汇报文字由研究 PDF、访谈纪要、数据集、历史版本和方法附录支持时，使用 `consulting-zh`。

重点核对“当前/最新”是否有时效证据，初步或区域性发现是否被过度外推，预测情景是否混用，以及引用和数字能否回到正确版本。

## 通用与专业规则包

没有合适行业规则包时使用 `generic-zh`。`lithium-demo` 只用于随附回归演示，不得把它描述成产品唯一行业。

## 需要补充配置或其他工作流协同的任务

- 招标条款与投标响应逐条核验：ClaimLedger 可完成事实承诺与证据一致性审计；标准技术偏离表、评分项判定和法律合规结论需要结构化条款、专用模板及专业复核规则。
- 联网核验外部事实：使用事实核查工作流。
- 敏感信息检测：使用隐私扫描工具。
- 文档写作或总结：先使用写作工作流，再由 ClaimLedger 审计成稿。
- 检索问答：使用 RAG；ClaimLedger 只审计已经完成的交付材料。
