# 规则包

规则包是 `assets/rules` 中经过白名单限制的 YAML 文件。确定性规范化逻辑放在引擎中，行业词汇放在规则包中。

行业规则包用于定义：

- 互斥的主体、产品、地区、税费、运费、时间窗口和分母口径；
- 来源权威级别对应的文件名模式；
- 时效窗口、OCR 复核阈值、检索阈值和风险级别策略；
- 别名和专业术语。

每个互斥分类组必须包含 `id`、`issue_code` 和 `values` 映射。冲突说明必须展示双方实际识别到的类别。规则不得虚构事实、证据原文或来源位置。

始终先加载通用规则包。行业列表在通用列表上扩展；行业标量或字典设置覆盖通用设置。新增规则包时，同时加入 `JobRequest` 白名单和 CLI 选项，并补充接口契约测试。
