# 审阅记忆与策略

审阅记忆只是提供建议的反馈层，不是自动训练。

## 岗位模板

- `generic`：关注缺少证据和直接冲突。
- `audit`：关注数值冲突、来源权威性和定位质量。
- `operations`：关注 KPI 数值、单位、期间和衍生计算。
- `consulting`：关注措辞强度、样本外推、情景、来源冲突和时效性。

创建命名配置并通过 `--review-profile` 使用。任务创建时固定岗位模板和已激活策略的哈希；以后修改策略不能改变历史任务。

## 记忆含义

- `accept`：已确认的风险先例，但不能解除本次风险。
- `reject`：可能的误报先例，只在问题范围高度一致时展示。
- `replace`：措辞修正先例，再次使用时仍须根据当前证据复验。
- `waive`：仅作为审计历史保存，不能升级为策略，也不能视为支持证据。

跨任务只保存结论短句、规范化事实、问题代码、理由和来源标识，不复制证据原文。记忆只保存在本机、配置之间相互隔离、可以删除，默认 365 天后过期。

## 策略生命周期

1. 展示命中的历史先例和匹配因素。
2. 人工填写理由后才能生成策略草稿。
3. 再次明确确认并填写理由后才能激活。
4. 已激活策略只影响新任务。
5. 策略可以提高关注度或风险级别，但不能修改审计状态或自动创建解除风险的决定。
6. 已激活版本只能停用，不能原地改写。

不得自动创建、激活、停用、驳回、修正或豁免。
