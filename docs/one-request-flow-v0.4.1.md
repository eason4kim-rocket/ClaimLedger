# ClaimLedger v0.4.1 一句话流程验证

## 已验证

- Qoder 能发现并调用 `claimledger-audit`。
- 新会话中的运营月报请求会路由到 `operations-zh`。
- Skill 明确区分执行 profile 与审阅记忆模板：普通自然语言审计固定使用 `lite`；`operations` 只可作为可选审阅模板。
- 仅当用户给出“启用 Balanced”或“use the Balanced profile”一类明确祈使指令时，才允许进入 Balanced 检查。问题、比较、粘贴材料或能力说明中出现 “Balanced” 不构成授权。
- 已安装环境的正常路径由 Skill 编排 `doctor → models status → audit --open`，不要求用户复制 CLI。
- 本地复核页实际打开，显示“自动审计、人工复核、可信交付”三阶段。
- 11 项高风险未处理时，最终交付按钮在前端即为禁用状态。
- 标准产物显示为四个明确下载入口；最终稿只有生成后才出现。
- 下载 API 使用固定 kind 白名单、任务归属、路径边界、文件哈希和会话令牌校验。

## 人工边界

本轮创建了运营审阅任务并将本地页面留给用户。系统没有自动执行 `reject`、`replace` 或 `waive`，也没有代替用户决定 11 项高风险。因此当前状态准确记录为：

> 技术门禁与界面闭环通过；真人决定闭环待用户完成。

不能把黄金标签、自动测试决定或开发者模拟冒充真人审阅。
