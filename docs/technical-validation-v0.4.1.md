# ClaimLedger v0.4.1 技术验证报告

> 本报告只记录 2026-07-19 已实际运行的能力。发布、文章、视频和比赛报名由用户自行完成。

## 1. 本轮收口结果

v0.4.1 没有增加行业或重跑 8B，重点完成普通用户的一键真实交付：

- Qoder 默认编排 Lite，并自动选择采购、运营、咨询或通用规则包。
- 复核页增加三阶段状态、前端交付门禁和明确下载入口。
- 新增只读产物下载 API，校验令牌、任务、白名单、路径和 SHA-256。
- 审计输出统一返回任务 ID、风险摘要、未处理阻断数、复核链接和单一步骤。
- Balanced 改为严格显式 opt-in；普通请求、问题或比较中提到 Balanced 都不会授权启用。
- 临时模型网关在完成、失败或中断后按精确 PID 清理。

## 2. Lite 三行业回归

环境：MacBook Air，Apple M3，24 GB；Python 3.11；PaddlePaddle 3.3.1；PaddleOCR 3.7.0；PP-OCRv5 Mobile 本地缓存。

| 案例 | 结论 | 植入风险 | 总耗时 |
|---|---:|---:|---:|
| 采购与供应商评估 | 44 | 23 | 52,135 ms |
| 运营月报 | 28 | 12 | 1,402 ms |
| 咨询市场研究 | 28 | 14 | 1,450 ms |

本批次峰值 RSS：3,062,497,280 bytes。采购包含扫描 PDF、TIFF、JPG 和回单，OCR 是主要耗时；运营、咨询主要使用文本层。

- 结构化结论提取 Precision / Recall / F1：100% / 100% / 100%。

- 严格证据 Top-5 召回率：91%。
- 状态准确率：97%。
- Issue-code Micro / Macro F1：79.25% / 80%。

机器结果：`docs/results/golden-v041.json`。三案 v0.4.1 标准产物均重新生成；黄金标签没有被写成人工决定。

## 3. Web、API 与安全

- Chrome 实际打开本机运营复核任务。
- 页面显示“自动审计完成、人工复核待处理、可信交付待生成”。
- 11 项高风险未处理时，最终交付按钮为 disabled。
- 标准产物显示带批注报告、证据台账、审计 JSON、Manifest 四个下载入口。
- 下载 API 自动化覆盖无令牌、错误令牌、错误任务、路径穿越、哈希变化和未生成最终稿。
- socket 守卫只允许 loopback；完成一次 Lite 文本层审计，记录到的非回环连接尝试为 0。

## 4. Qoder 路由

全新 Qoder 会话的运营月报路由测试发现并使用 `claimledger-audit`，选择 `operations-zh`。本轮同时消除了“执行 profile”和“审阅记忆模板”同名造成的歧义：

- 执行 profile：普通自然语言请求固定为 `lite`。
- 规则包：运营月报为 `operations-zh`。
- 审阅模板：只有用户要求记忆偏好时才可选 `operations`。
- Balanced：只有明确祈使式 opt-in 才允许检查和启动。

负向边界测试仍明确拒绝“招标条款与投标响应逐条合规比对/技术偏离表”，避免与招投标合规 Skill 重叠。

## 5. WPS

WPS Office Mac 12.1.26026 实际打开三案的带批注 DOCX 与 Excel 台账：

- 无文件修复警告。
- 中文、表格、分页和原生批注可读。
- Excel 筛选、冻结窗格、状态颜色、长文本和多工作表可用。

详见 `docs/wps-validation-v0.4.1.md`。本轮不认证 Pages 或 Microsoft Word。
