# ClaimLedger v0.5.0 已实测能力清单

以下内容可以用于技术说明，且不超出本轮实测边界：

- 对 DOCX 成稿和 PDF、DOCX、XLSX、PNG、JPG、TIFF 本地证据包执行交付前审计。
- 默认 Lite；仅扫描页和图片触发 PP-OCRv5 Mobile，文本层材料不重复 OCR。
- 核对数字、日期、单位、币种、主体、地区、统计口径、来源冲突、弱支持和过期表述。
- 保留 PDF 页码与坐标、Word 段落或表格、Excel 工作表与单元格、图片 OCR 坐标。
- 在 Qoder 对话中提供中文可信交付台；不可渲染时退化为中文 Markdown 简报。
- 卡片按钮只表达中文意图，修正、驳回和豁免仍要求明确人工确认。
- 本地审阅页支持证据对照、稳定锚点、筛选、页面内决定模态框、重新核证和交付闸门。
- 输出带批注 Word、Excel 证据台账、审计 JSON、产物清单和人工门禁通过后的新 DOCX。
- 服务仅监听 localhost；模型、证据、决定和导出没有云端降级路径。
- 87 项自动化测试通过；三行业合成黄金集风险 Recall 97.96%、Precision 100%、严格证据 Top-5 Recall 91%。
- 最终 ZIP、wheel 和魔搭上传目录已生成；两次构建逐字节一致。
